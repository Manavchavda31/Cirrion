# Real project screenshots

Drop real screenshots here and the site picks them up automatically (no code change):

    public/projects/<project-slug>/cover.png      hero image (16:10 or 16:9 works best, 1600px+ wide)
    public/projects/<project-slug>/shot-1.png     gallery images, shot-1 ... shot-6
    (.jpg, .jpeg and .webp also work)

Project slugs: elfworks-accounting, chatubix, prepstudy

Until an image exists, cards and case studies are text-only. Make sure any
screenshot is cleared for public use (client names, personal data and credentials removed).
